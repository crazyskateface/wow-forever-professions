# Professions.gg design references

These screenshots come from Alex Bristow's [Professions.gg case study](https://alexbristow.com/projects/professionsgg) and are retained locally as visual design references for this project.

- `blacksmithing-skill-up.png`: Blacksmithing recipe page showing skill-up success rates at different levels.
- `leatherworking-cost-estimation.png`: Leatherworking recipe page showing live-price cost estimates.

They are reference material, not application assets. Preserve the source attribution and do not ship them in the product without separate permission.
